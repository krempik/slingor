# SLINGOR.IO v1.4

Реальное время, мультиплеерная .io-игра: гравитационные пращи в космосе.
Сервер-авторитативная физика, боты, таблица лидеров.

## Что это

Пилоты управляют космическими зондами в 2D-арене вокруг звезды с планетами и
астероидами. Гравитация — главная механика:

- **Праща** — обогни планету на скорости → разгон ×1.35 и очки.
- **Цепь пращ** — ещё одна праща за 6 сек → очки ×2, ×3 … до ×5.
- **Ядра** — собирай. Гибель → контейнер с грузом падает к другим (26 сек — и исчезает).
- **Бонусы** — щит отражает удар, буст удваивает тягу, магнит тянет ядра.
- Столкновение с планетой = смерть.

## Архитектура

- **Сервер** (`main.py`, FastAPI + WebSocket) — авторитативная симуляция комнат по
  30 Hz, раздача состояния ~15 Hz, боты-наполнители, анти-абуз (rate limit,
  flood guard, oversize rejection).
- **Физика** (`game/physics.py`) — чистая, детерминированная, покрыта юнит-тестами.
- **ИИ ботов** (`game/ai.py`) — использует тот же вход через `Player.input`, что и люди.
- **Клиент** (`static/`) — «немое» вью: рендер, ввод, звук; правила не решает.

## Запуск

```bash
python -m venv venv
# Windows: venv\Scripts\activate ; Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
python main.py
```

Открой `http://127.0.0.1:8033`.

Либо просто запусти `run.bat` (Windows) — поднимет сервер и откроет браузер.

> Интерфейс на русском. Открывать `index.html` файлом (без сервера) нельзя —
> игра требует WebSocket-сервера.

## Тесты

```bash
python -m pytest
```

48 тестов: детерминированная физика (seeded RNG, fixed dt), ИИ ботов,
REST + WebSocket интеграция.

## Версия

Версия живёт в одном месте — `game/__init__.py` (`__version__`), и подаётся
клиенту через `/api/version`.

## Структура

```
slingor/
├── main.py                 # FastAPI-сервер, комнаты, WebSocket
├── requirements.txt
├── run.bat                 # Windows-запуск
├── game/
│   ├── physics.py          # авторитативная симуляция
│   ├── ai.py               # мозг ботов
│   ├── const.py            # тюнинг (единственный источник истины)
│   ├── database.py         # SQLite-таблица лидеров (WAL, кап 500)
│   └── __init__.py         # __version__
├── static/
│   ├── index.html          # меню + HUD
│   ├── game.js             # клиент (рендер, ввод, WS, звук)
│   └── style.css           # киберпанк-тема
└── tests/                  # 48 тестов (physics / ai / api)
```
